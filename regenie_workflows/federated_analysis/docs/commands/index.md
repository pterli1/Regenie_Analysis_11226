# Commands

The main subcommand, [`discover`](discover.md), runs a whole analysis. The others set up its environment or run one of its steps on its own, e.g. to check results or for analyses outside a FedCAT run.

```
fedcat [--version] <subcommand> [options]
```

--8<-- "commands.md"

`fedcat <subcommand> --help` prints a subcommand's options; each page here lists them in full. For all of them on one page, see [`docs/options_reference.md`](https://github.com/ExeterGenetics/biobank_workflows/blob/main/regenie_workflows/federated_analysis/docs/options_reference.md) on GitHub.
